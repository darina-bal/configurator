# Как добавить конфигуратор нового товара

Конфигуратор универсален: страница, галерея, шаги выбора, цена, наличие, блоки описания, таблица характеристик и блок скачивания строятся из **данных товара**. Новый товар — это новый файл данных и одна строка в каталоге; код интерфейса менять не нужно.

## 1. Подготовьте данные

Для товара нужно знать:

- **Опции** и их значения (например, «Трек»: встроенный / накладной; «Цвет»: белый / чёрный / …).
- **Позиции (SKU)** — по одной на каждую существующую комбинацию значений: артикул, цена, остаток, гарантия, фото, чертёж, характеристики.
- **Блоки описания** — плашки «заголовок + абзацы», как они стоят на странице товара (а если они зависят от опции — блоки для каждого SKU).
- **Видео товара** (необязательно): адрес mp4-файла или адрес встраиваемого плеера (Kinescope и т. п.) — берётся со страницы товара. Берите именно видео про этот товар: галерея показывает только материалы выбранного SKU, и заглушек быть не должно.

Источник — страница товара на centersvet.ru. Для текста, цен и остатков удобна SEO-разметка: каждая позиция лежит в блоке `<li class="seo">` («В наличии на складе: N шт.», «Срок гарантии: N»). Остальное — в отрисованной странице (откройте плашку позиции и посмотрите инструменты разработчика):

| Что                   | Где на странице сайта                                                                                                                                                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Блоки описания        | Серые плашки `promo-block` перед группой позиций: заголовок `promo-block__title`, абзацы разделены `<br><br>`.                                                                                                                              |
| Фото и чертёж         | Колонка `product-table__images`: первое `<img>` — фото, второе (`.schema`) — SVG-чертёж (`/media/uploads/svg/…` или `/media/uploads/shemu/…`).                                                                                              |
| Таблица характеристик | Строки `.node` (название `.name`, значение `.result`); порядок задаёт CSS-свойство `order`.                                                                                                                                                 |
| Файлы                 | Строки `.node-accordion__link`: названия, расширения и то, какие файлы у изделия есть. Адреса файлов не нужны — в прототипе это заглушки.                                                                                                   |
| Видео                 | Слайд `.slide-video` в блоке `.container-slider` (есть только в отрисованной странице): атрибут `data-video` — адрес плеера `https://kinescope.io/embed/<id>` или путь файла `uploads/video_main/<имя>.mp4` (на `cdn.centrsvet.ru/media/`). |

## 2. Создайте файл данных

`src/entities/product/api/data/<имя-товара>.ts` — по образцу [`loop-rt.ts`](../src/entities/product/api/data/loop-rt.ts) (одна опция) или [`locus-duo.ts`](../src/entities/product/api/data/locus-duo.ts) (две опции, описание и чертёж зависят от трека):

```ts
import type { Product, ProductVariant } from '../../model/types';
import { buildSpecs } from './build-specs';
import { FINISH } from './finishes';
import { mediaUrl, variantFiles } from './sources';

function createVariant(/* … */): ProductVariant {
  return {
    sku: 'ART.123',
    selection: { finish: FINISH.paintWhite.id }, // по значению на каждую опцию товара
    price: 4800,
    stock: 162,
    warranty: 2,
    photo: { src: mediaUrl('svetilnik/…/photo.jpg'), alt: 'Название — Белый' },
    diagram: { src: mediaUrl('svg/scheme.svg'), alt: 'Название — чертёж с размерами' },
    specs: buildSpecs({
      series: 'MY.PRODUCT', // строка «Название» в таблице
      sku: 'ART.123',
      finish: 'PAINT WHITE',
      power: 12,
      cct: 3000,
      angle: 'Medium',
      ip: 44,
      voltage: 220,
      warranty: 2,
    }),
    files: variantFiles(), // 3D Files, DIALux, Паспорт и инструкция — как на сайте
  };
}

export const myProduct: Product = {
  slug: 'my_product', // адрес: /product/my_product
  name: 'MY.PRODUCT',
  description: [{ title: 'MY.PRODUCT', paragraphs: ['Первый абзац.', 'Второй абзац.'] }],
  options: [
    {
      id: 'finish',
      label: 'Цвет',
      description: 'Выберите отделку корпуса.',
      kind: 'swatch',
      values: [FINISH.paintWhite, FINISH.paintBlack],
    },
  ],
  variants: [/* createVariant(...) на каждый SKU */],
  // Общие слайды галереи: видео файлом ('video') или плеером в iframe ('embed').
  extraMedia: [
    {
      id: 'video',
      kind: 'video',
      src: mediaUrl('video_main/my_product.mp4'),
      label: 'Видео',
      alt: 'Видео о светильнике MY.PRODUCT',
    },
  ],
};
```

### Справочник полей

**`Product`**

| Поле          | Назначение                                                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `slug`        | Адрес `/product/:slug`; только `[a-z0-9_-]`. Для товаров, что есть на сайте, совпадает с их slug.                                   |
| `name`        | Название — заголовок страницы и карточки.                                                                                           |
| `description` | Блоки описания (`DescriptionBlock[]`) для SKU, у которых нет собственных; первый абзац первого блока — подпись карточки в каталоге. |
| `options`     | Шаги конфигуратора, в порядке показа.                                                                                               |
| `variants`    | SKU. Порядок важен: первый SKU в наличии выбирается по умолчанию.                                                                   |
| `extraMedia`  | Общие слайды галереи (видео, изображения): идут после фото и чертежа выбранного SKU. Подробности — ниже.                            |

**`DescriptionBlock`**: `title` (заголовок плашки: `LOOP.RT`, `SUPERSLIM (DALI)`), `paragraphs` (абзацы).

**`ProductOption`**: `id` (имя параметра в URL: `?finish=…`), `label` (заголовок шага), `description`, `kind` (`'card'` — карточки с названием и подсказкой; `'swatch'` — цветные кружки), `values`.

**`OptionValue`**: `id`, `label` (для покупателя), `code` (оригинальное название с сайта), `hint` (подпись карточки), `swatch` (CSS-цвет; обязателен для `kind: 'swatch'`).

**`ProductVariant`**: `sku`, `selection` (значение каждой опции), `price` (₽, целое), `stock` (шт.), `warranty` (лет), `photo`, `diagram` (чертёж — SVG; необязателен), `specs`, `files`, необязательное `description` (заменяет блоки описания товара — так сделано в LOCUS DUO, где текст зависит от трека).

**`ExtraMedia`** (общий слайд галереи): `id` (уникален в пределах товара; `photo` и `diagram` заняты слайдами SKU), `label` (подпись превью), `alt` (для видео — его название: подпись кнопки и заголовок плеера), `src` и вид слайда `kind`:

- `'video'` — файл (`.mp4`), играет тег `<video>` с элементами управления; необязательный `poster` (по умолчанию — фото выбранного SKU);
- `'embed'` — плеер стороннего сервиса (адрес для iframe, например `https://kinescope.io/embed/…`): сначала показывается постер, плеер подключается по нажатию; необязательный `poster`;
- `'image'` — картинка; необязательный `fit` (`'cover'` — заполнить кадр, `'contain'` — вписать целиком).

Галерея выбранного SKU собирается автоматически: **фото SKU → его чертёж (если задан `diagram`) → слайды `extraMedia`**. Превью под слайдером и полноэкранная галерея (она открывается по нажатию на фото или чертёж) — те же слайды, поэтому у каждого цвета и трека в галерее только «свои» фото и чертёж.

**`SpecItem`** (строка таблицы): `label`, `value`. Не собирайте массив вручную — `buildSpecs()` выдаёт строки в порядке и с названиями сайта: Название, Артикул, Отделка, Мощность, Управление, Температура, Цветопередача, Качество света, Пульсация, Подключение, Угол света, Влагозащита, Гарантия; значения в формате сайта («12W», «3000K», «220V», «IP44»).

**`ProductFile`** (строка блока скачивания): `title`, `format` (расширение без точки), `kind` (`'3d'` — значок-куб, `'document'` — галочка в рамке), `available` (файл у изделия есть). Если файла нет (`available: false`), строка показывается приглушённой и не кликабельной — так на сайте выглядят «3D Files» и «DIALux», когда их нет. Если файл есть, строка — ссылка-заглушка: адреса у файла нет, потому что прототип не ссылается на сайт. `variantFiles()` собирает три стандартные строки блока.

### Типичные случаи

- **Неполная матрица** (нет какой-то комбинации): допустимо. При выборе значения, дающего несуществующую комбинацию, движок автоматически подберёт ближайший реальный SKU.
- **Несколько плашек описания**: перечислите их в `description` в порядке сайта (у LOCUS DUO — «SUPERSLIM (DALI)», «ТРЕКИ»/«ТРЕК», «SSD.LOCUS»).
- **Чертёж общий для всех отделок** (как у LOOP.RT) — один и тот же `diagram` у всех SKU; **свой на каждую модификацию** (как у LOCUS DUO) — по значению опции.
- **Чертёж в галерее** появляется сам, если у SKU задан `diagram` (слайд «Чертёж» сразу после фото). Фото и чертёж показываются только в галерее: блок под конфигуратором (описание, характеристики, файлы) их не повторяет.
- **Видео, общее для нескольких SKU** (так у обоих товаров): один элемент в `extraMedia`. Если у товара нет видео, поле можно не задавать — галерея будет из фото и чертежа.
- **Видео в iframe**: используйте `kind: 'embed'` и адрес вида `https://kinescope.io/embed/<id>` — он берётся из `src` iframe на странице товара.
- **Новая отделка**: добавьте её в [`finishes.ts`](../src/entities/product/api/data/finishes.ts) (общий словарь) — цвет кружка подбирайте по фото товара.
- **Товар без остатка**: `stock: 0` — значение остаётся выбираемым, но помечается «Нет в наличии» (красная точка в блоке цены), а количество и кнопка корзины отключаются.
- **Как показывается остаток** (`stock`): от 50 — «В наличии N шт» (зелёная точка); 1–49 — «В наличии менее 50 шт» (жёлтая; точное число не раскрывается — так на сайте); 0 — «Нет в наличии». Покупатель может положить в корзину не больше `stock` с учётом уже лежащего в корзине.
- **Ссылок на сайт в данных нет.** Не добавляйте адреса страниц и файлов centersvet.ru (паспорта, инструкции, 3D-модели): прототип на сайт не ссылается, строка файла — ссылка-заглушка. Тест `app/routes.test.tsx` падает, если на страницах появляется ссылка за пределы прототипа.

## 3. Зарегистрируйте товар в каталоге

В [`src/entities/product/api/catalog.ts`](../src/entities/product/api/catalog.ts) добавьте товар в массив `products`. Он сразу появится на главной и по адресу `/product/<slug>`.

## 4. Проверьте данные тестами

```bash
npm test
```

Тест каталога прогоняет `validateProduct` по **каждому** товару и сообщает понятные ошибки: дубли SKU и комбинаций, неизвестные значения опций, значение без единого SKU, некорректные цена/остаток/гарантия, битые URL (фото, чертёж, слайды), пустые блоки описания, отсутствие цвета у свотча, неуникальные и зарезервированные (`photo`, `diagram`) id слайдов. Тест «блок скачивания» дополнительно проверяет состав строк файлов у каждого SKU. Дополните [`catalog.test.ts`](../src/entities/product/api/catalog.test.ts) проверками, важными именно для нового товара (число SKU, цены, недоступные позиции).

## 5. Проверьте в браузере

```bash
npm run dev
```

Откройте `/product/<slug>`: смена каждой опции должна менять цену, остаток, блоки описания, характеристики и галерею — в слайдере и превью под ним должны остаться только фото, чертёж и видео выбранного варианта (кадр плавно перетекает в новый); в адресе страницы появляются параметры (`?track=surface&finish=paint-white`) — такую ссылку можно отправить коллеге. Проверьте, что видео запускается (файл — кнопкой плеера, `embed` — нажатием на постер). Сравните блоки под конфигуратором со страницей товара на centersvet.ru.
