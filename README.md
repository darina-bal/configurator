# Конфигуратор светильников (прототип)

Набросок конфигуратора товара для сайта centersvet.ru: оформление — в стилистике сайта (монохром, Montserrat, светлая тема; блоки под конфигуратором — серые скруглённые плашки, как на страницах товаров; шапка и подвал — заглушки по образцу сайта), логика и раскладка — как у конфигуратора Apple Watch (галерея слева, шаги выбора справа, цена, количество и кнопка «в корзину» внутри блока опций).

Конфигураторов будет много (почти на каждый товар), поэтому ядро универсально: товар описывается данными (опции + матрица SKU), а интерфейс и логика общие. Пока реализованы два товара: **LOOP.RT** (выбор цвета) и **LOCUS DUO** (выбор трека — встроенный или накладной — и цвета).

## Возможности

- **Универсальный конфигуратор.** Набор шагов (опций) определяется данными товара: у LOOP.RT один шаг («Цвет»), у LOCUS DUO два («Трек», «Цвет»). Новый товар — новый файл данных, код менять не нужно ([как добавить](docs/adding-a-product.md)).
- **Раскладка как у Apple.** Слева липкая галерея, справа шаги выбора, под ними — блок цены с наличием, количеством и кнопкой корзины.
- **Блок цены — как на centersvet.ru**, но в правой колонке: серая плашка, слева «Цена с НДС 22%», цена и наличие с цветной точкой, справа (за вертикальным разделителем) количество со степпером «− 1 +» и серая кнопка с иконкой корзины. Артикул и гарантия под блоком не дублируются — они есть в таблице характеристик ниже. Размеры, шрифты и цвета сняты с живой страницы сайта, три ступени адаптива подстраиваются под ширину блока (крупная, компактная, в два ряд).
- **Шапка и подвал — заглушки по образцу centersvet.ru.** Шапка: логотип (ведёт на главную прототипа), меню «Продукты / Контакты / Компания / Поиск», значки международной версии, корзины со счётчиком и кабинета; на экранах уже 1024 px — кнопка меню и панель на весь экран, как на сайте. Подвал: чёрный, семь строк-аккордеонов («Наши консультанты», «Наши шоурумы», «Наши соцсети», «Кабинет дизайнера», «О компании», «Контакты», «Карьера») с «плюсом» справа и копирайтом. **Ссылок на сайт нет:** пункты меню, значки и пункты подвала — ссылки-заглушки (выглядят как на сайте, но без адреса: нажатие ничего не делает и вкладок не открывает), в соцсети и на страницы centersvet.ru из прототипа не попасть. На сайте у меню есть выпадающие подменю и шапка прячется при прокрутке вниз — здесь этого нет.
- **Блоки под конфигуратором — как на странице товара centersvet.ru:** плашки описания (заголовок и текст, у LOCUS DUO — три плашки серии), ниже слева серая плашка с таблицей характеристик, а справа от неё — плашка «блока скачивания» (3D Files, DIALux, Паспорт и инструкция). Фото и чертёж здесь не повторяются: они показаны только в галерее. На узких экранах плашки идут друг под другом: таблица, затем файлы.
- **Всё зависит от выбранного SKU:** цена, остаток («В наличии 162 шт» / «В наличии менее 50 шт» / «Нет в наличии» с зелёной, жёлтой и красной точкой), доступность кнопки, блоки описания, характеристики, галерея (фото, чертёж, видео).
- **Подсказки в самих опциях:** пометка «Нет в наличии» и перечёркнутый цвет-свотч. Цен и надбавок в опциях нет: цена считается и показывается только в блоке цены (и при добавлении в корзину).
- **Галерея выбранного светильника на Swiper:** слайды и превью под ними — только фото выбранного SKU, его чертёж размеров и видео (выбран белый цвет — фото белого светильника; выбран накладной трек — чертёж накладного). Вся галерея — это три слайда, и при смене опции они остаются на месте, меняется их содержимое: кадр, который смотрит пользователь, не сбрасывается. Смена опции плавно перетекает в новый кадр (перекрёстное затухание), листание галереи на выбор не влияет. **Слайдер ведёт себя как на centersvet.ru:** кадры прокручиваются по горизонтали (0,6 с), после последнего снова первый; листают кликом по краям кадра (зоны по 30 % ширины, при наведении проявляется стрелка; с 768 px) и свайпом, а также миниатюрами под кадром; рамка и превью под ней скруглены (5 px, от 900 px — 10 px). Нажатие на кадр картинки открывает **полноэкранную галерею**: чёрный экран, кадр по центру, крестик, счётчик «1 / 3», стрелки (у краёв экрана от 1280 px, ниже — по бокам счётчика), листание клавишами ←/→ и свайпом, закрытие крестиком или Esc. Галерея — нативный `<dialog>`: страница под ним не прокручивается и остаётся на прежнем месте, фокус возвращается на кадр, с которого открыли. Видео-слайды играют на месте, как раньше. Чёрточек-индикаторов, как у сайта, нет — их заменяют миниатюры.
- **Выбор хранится в адресе страницы** (`?track=surface&finish=paint-white`): ссылку на конкретную конфигурацию можно отправить, кнопки «назад/вперёд» работают.
- **Корзина-заглушка:** значок со счётчиком в шапке (рядом с остальными значками, как на сайте), сохранение в `localStorage`; количество выбирается в блоке цены и ограничено остатком с учётом уже лежащего в корзине.
- Адаптивная вёрстка (от 390 px), клавиатурная доступность (нативные radio, a11y-подписи слайдера по-русски), поддержка `prefers-reduced-motion` (кадры меняются без анимации). Хлебных крошек на странице нет.

## Быстрый старт

Нужен Node.js ≥ 22.18 (проверено на 24).

```bash
npm install
npm run dev        # http://localhost:5173
```

Страницы: `/` — каталог, `/product/loop_rt_main` и `/product/locus_duo` — конфигураторы.

## Деплой на Vercel

Приложение — статический SPA: `npm run build` собирает его в `dist/`, переменных окружения нет. Vercel сам определяет Vite (команду сборки и папку `dist/`) и ставит dev-зависимости, нужные для сборки; версию Node берёт из `engines` в `package.json` (диапазон `>=22.18.0` подходит под 24.x, на которой проект и проверялся).

Единственный файл настроек — [`vercel.json`](vercel.json): правило `rewrites` отдаёт `index.html` на любой адрес, которого нет среди файлов сборки. Без него прямой заход на `/product/locus_duo?track=surface` (ссылка на конфигурацию, обновление страницы) закончился бы ответом 404: страницы существуют только в клиентском роутере. Побочный эффект: адрес, которого нет в приложении, тоже получает `index.html` с кодом 200, а страницу «не найдено» рисует само приложение.

## Как это работает

**Данные → SKU → интерфейс.** Товар (`Product`) состоит из опций (`options`) и позиций (`variants`). Позиция — это одна комбинация значений опций (`selection: { track: 'surface', finish: 'paint-white' }`) со своей ценой, остатком, фото, чертежом, характеристиками, файлами и (при необходимости) блоками описания. Тип данных и справочник полей — в [docs/adding-a-product.md](docs/adding-a-product.md).

**Выбор опций.** Состояние конфигуратора — параметры адреса страницы; хук `useProductConfigurator` разбирает их в выбор и находит SKU. Если выбранной комбинации не существует (например, нет «накладной × золото»), движок подбирает ближайший реальный SKU — выбор всегда указывает на существующую позицию. Пустой или некорректный адрес даёт первый SKU, который есть в наличии. Для каждого значения опции заранее считается, что получится при его выборе: есть ли оно в наличии. Цена в опциях не считается — она показывается только в блоке цены.

**Галерея.** В слайдер кладутся материалы **только выбранного SKU** (`buildGallerySlides`): его фото (слот `photo`), его чертёж (`diagram`, если есть) и общие слайды товара (`extraMedia`, сейчас — видео); постер видео — фото выбранного SKU. Миниатюры под слайдером строятся из тех же слайдов, поэтому показывают ровно эти три кадра. Слайды — «слоты»: при смене SKU их `id` те же, и Swiper не пересоздаётся, а подменяет содержимое, так что активный слайд сохраняется.

**Плавная смена кадра** при выборе опции — нативный View Transitions API браузера: хук `useProductConfigurator` обновляет адрес через роутер с `viewTransition: true`, а блок галереи вынесен в отдельный слой перехода (`view-transition-name: product-gallery`, стили — [`shared/styles/_view-transitions.scss`](src/shared/styles/_view-transitions.scss)). Остальная страница в переходе не участвует: цена и текст меняются сразу, затухает только галерея (500 мс). Фото и чертежи остальных SKU подгружаются заранее в простое браузера ([`preloadImages`](src/shared/lib/preload-image)), чтобы кроссфейд не ждал сеть. В браузерах без View Transitions и при «уменьшить движение» кадр меняется сразу, функциональность не страдает. Листание самого слайдера (зоны по краям, миниатюры, свайп) анимирует Swiper: прокрутка по горизонтали 600 мс, `ease-in-out`, как у слайдера сайта; при «уменьшить движение» — без анимации. Слайдера «на заказ» в проекте нет — только тонкая обёртка над Swiper ([`shared/ui/media-slider`](src/shared/ui/media-slider)): обычный слайдер (`MediaSlider`), полноэкранная галерея (`MediaLightbox`, второй экземпляр Swiper в `<dialog>`; при открытии встаёт на нужный кадр, при закрытии обычный слайдер переходит на кадр, где остановились) и общий для обоих компонент слайда (`SlideMedia`: картинка, видео или плеер-постер). Зацикливание — режим `loop` Swiper 14: слайды не дублируются, а переставляются.

**Блоки под конфигуратором** ([`widgets/product-details`](src/widgets/product-details)) повторяют вёрстку раскрытой позиции на centersvet.ru: серые плашки `#f5f5f5` со скруглением 10 px (5 px на мобильных), таблица характеристик с разделителями строк и приглушёнными названиями (`opacity .6`; значения — в правой колонке ~37 %) и блок скачивания со значками и расширениями. На десктопе таблица занимает левую колонку (7/12), блок скачивания — правую (5/12), прижат к верху (на сайте он стоит под таблицей, а справа — фото и чертёж; здесь фото и чертёж убраны как дубли галереи, а на их место переехал блок скачивания). Размеры, отступы и цвета сняты с живой страницы сайта.

**Блок цены** ([`widgets/product-configurator`](src/widgets/product-configurator) + [`features/add-to-cart`](src/features/add-to-cart)) повторяет `.price-block` со страниц товаров centersvet.ru: плашка `#f5f5f5` (скругление 10 px, на мобильных 5 px) с рамкой 1 px того же цвета; «Цена с НДС 22%» — 12 px, цена — 23.57 px / вес 500 / межбуквенный 0.04em; точка наличия 9 px (`#35f300` — от 50 шт., `#f3cf00` — меньше 50, `#f30000` — нет); разделитель 1×47 px; подписи «Количество» и «В корзину» — 14 px; степпер 146×42 px с рамкой `#d9d9d9` (радиус 4 px), кнопка корзины 94×42 px (`#e5e5e5`, радиус 5 px) с иконкой с сайта. Блок живёт в узкой правой колонке, поэтому ступень размеров выбирается по ширине самого блока (container queries), а не экрана: от 540 px — крупные размеры сайта (с чуть уменьшенными отступами), 350–539 px — компактные размеры, которые сайт использует на планшетах и телефонах (подписи 9 px, степпер 26 px, кнопка 64×28 px), уже 350 px — те же элементы в два ряда. Подписи наличия — по правилам сайта: «В наличии N шт» (от 50), «В наличии менее 50 шт» (1–49, точное число не раскрывается), для нулевого остатка вместо сайтового «Доступно для заказа» — «Нет в наличии» и отключённые элементы (товар без остатка у нас не продаётся). Подписи над степпером и кнопкой («Количество», «В корзину») — наши: на сайте они относятся к «проекту» и «избранному».

**Корзина.** Количество выбирается степпером или вводом числа (от 1 до остатка с учётом того, что SKU уже лежит в корзине); кнопка с иконкой корзины добавляет выбранное количество, на пару секунд превращается в чёрную с галочкой и подписью «Добавлено», а когда в корзине оказался весь остаток — отключается («Весь остаток в корзине»). Счётчик в шапке обновляется сразу, данные лежат в `localStorage` под ключом `configurator:cart`. Страницы корзины и оформления в прототипе нет.

**Шапка, подвал и контейнер страниц.** Шапка ([`widgets/site-header`](src/widgets/site-header)) и подвал ([`widgets/site-footer`](src/widgets/site-footer)) повторяют шапку и подвал centersvet.ru: размеры, шрифты и отступы сняты с живой страницы и сверены на ширинах 390–1440 px. Логотип — svg с сайта. В полной шапке (от 1024 px) меню стоит по центру (кегль 11 / 14 / 16 px по ширине экрана), значки — справа; на экранах уже 1024 px слева кнопка меню (открывает белую панель на весь экран; закрывается по Escape, по нажатию на логотип и когда фокус уходит из шапки — Tab за её пределы или нажатие на пункт-заглушку, который не фокусируется), логотип по центру, справа корзина. Работают только логотип (ведёт на главную прототипа) и счётчик корзины ([`CartIndicator`](src/entities/cart)); остальное — заглушки. Подвал собран из нативных `<details>`: клавиатура и состояние «раскрыто» работают без своего кода; состав — данные в [`config/footer-rows.ts`](src/widgets/site-footer/config/footer-rows.ts) (только названия, адресов нет). Ссылки-заглушки — компонент [`StubLink`](src/shared/ui/stub-link): `<a>` без `href`, который выглядит как ссылка (курсор, подсветка при наведении), но не переходит, не открывает вкладок и не получает фокус с клавиатуры. Шапка, страницы и подвал делят один контейнер, как на сайте (`.container`): поля 15 px на телефонах, 30 px на планшетах и 3 % ширины на десктопе, шире 1880 px он не растёт. Высота шапки (75 px на десктопе, 51 px ниже) — токен `--header-height`: от него считается положение липкой галереи. Зазор между галереей и правой колонкой равен полям страницы: от ширины колонки зависит ступень блока цены (крупная — от 540 px), и на экране 1440 px (1425 px с полосой прокрутки) блок остаётся крупным.

**Маршруты.** Товар загружается loader'ом маршрута `/product/:slug`: неизвестный slug даёт ту же страницу «не найдено», что и неизвестный адрес. Loader не перезапускается при смене опций (меняются только параметры запроса).

## Данные и допущения

Данные — статические модули в [`src/entities/product/api/data/`](src/entities/product/api/data), снимок с centersvet.ru на **12.10.2026**; при подключении бэкенда меняется только слой `api` ([catalog.ts](src/entities/product/api/catalog.ts)).

| Товар         | Страница-источник на centersvet.ru                        | SKU                   |
| ------------- | --------------------------------------------------------- | --------------------- |
| **LOOP.RT**   | `/product/loop_rt_main/`                                  | 4 (отделки)           |
| **LOCUS DUO** | `/product/superslim_dali/` и `/product/sps_dali_surface/` | 6 (2 трека × 3 цвета) |

Страницы указаны путями, а не гиперссылками: прототип не ссылается на сайт.

Что важно знать:

- **LOOP.RT** на сайте — только 4 отделки, выбора трека у него нет; поэтому у него одна опция «Цвет». Цена у всех отделок одна (4 800 ₽), различается остаток.
- **LOCUS DUO собран из двух страниц сайта.** На centersvet.ru нет карточки, где трек выбирается внутри одного товара: встроенные и накладные треки — отдельные страницы. Встроенный (`SSD LOCUS TURN DUO 22`, 4 Вт) и накладной (`SSD LOCUS DUO 50`, 8 Вт) — разные изделия, различия видны в характеристиках, цене (10 800 / 18 600 / 20 800 ₽), фото и чертеже. «Патина» нет в наличии на обоих треках — так демонстрируется недоступность.
- **Блоки описания — те же плашки, что на страницах сайта**, с их заголовками и текстом: у LOOP.RT одна («LOOP.RT»), у LOCUS DUO три — «SUPERSLIM (DALI)», «ТРЕКИ» / «ТРЕК» (по типу трека) и «SSD.LOCUS».
- **Таблица характеристик — в формате сайта**: те же названия строк, порядок и значения («Название, Артикул, Отделка, Мощность 12W, Управление, Температура 3000K, Цветопередача, Качество света, Пульсация, Подключение 220V, Угол света, Влагозащита IP44, Гарантия»). «Название» у LOCUS DUO — `SUPERSLIM DALI` (так на сайте). На сайте «Отделка» и «Температура» у LOCUS DUO — выпадающие списки внутри группы; у нас выбор делается в конфигураторе, а в таблице — значение выбранного SKU. Иконок-подсказок рядом с названиями в видимой таблице на сайте нет, поэтому их нет и здесь. Названия отделок в опциях — по-русски, оригинальное название (PAINT WHITE) показано рядом.
- **Блок скачивания** — три строки, как на сайте: «3D Files» (`.rar`) и «DIALux» (`.rar`) у этих изделий без файлов, поэтому приглушены и не кликабельны; «Паспорт, инструкция» (`.pdf`) — ссылка-заглушка без адреса: на сайте это PDF, но скачивать из прототипа нечего (ссылок на сайт в нём нет). Поэтому и паспорт не зависит от выбранного SKU — строка у всех одинаковая.
- **«Количество» в данных — это остаток на складе** (`stock`; на сайте он виден как «В наличии 162 шт»). Количество к покупке покупатель выбирает сам в блоке цены; оно не больше остатка.
- **Фото, чертежи и видео-файл — внешние ресурсы CDN сайта** (`cdn.centrsvet.ru`; в репозиторий не копируются, без доступа к CDN они не загрузятся). Кроме них (и плеера Kinescope у LOOP.RT, см. ниже) прототип ничего не берёт с сайта: ссылок на страницы и файлы сайта в нём нет. Используются только фото и чертежи, уже размещённые на страницах товаров: по одному фото на SKU и одному SVG-чертежу на группу (у LOOP.RT — один на все отделки, у LOCUS DUO — свой на каждый трек). Фото тяжёлые (2560×1440): показывается одно за раз, остальные подгружаются заранее в простое браузера. Чертежи свои не рисовались.
- **Видео — настоящие, со страниц сайта** (заглушки-баннера больше нет). У LOOP.RT — ролик с его страницы на Kinescope: он встраивается через iframe и подключается только по нажатию на постер, чтобы страница не грузила тяжёлый плеер зря; при уходе со слайда плеер возвращается к постеру. У LOCUS DUO — ролик серии SUPERSLIM DALI (mp4 с CDN сайта) со страницы встроенных треков; у страницы накладных треков своего видео нет, поэтому видео общее для обоих треков.
- **Галерея** содержит фото выбранного SKU, чертёж и видео. Фото и чертёж показаны только в галерее: блок под конфигуратором их не повторяет (на сайте они стоят и рядом с таблицей характеристик — здесь убраны как дубли).
- **Цвета свотчей** подобраны по фото товаров и общие для всех товаров (словарь [`finishes.ts`](src/entities/product/api/data/finishes.ts)).
- **Шапка и подвал — заглушки без ссылок.** Пункты меню, значки международной версии и кабинета и все пункты подвала (включая соцсети и вакансии) — ссылки-заглушки без адреса: ни на centersvet.ru, ни во внешние сервисы из прототипа не ведёт ничего, кроме логотипа (он открывает главную прототипа). Названия пунктов и состав подвала сняты с сайта 12.10.2026. На сайте «Продукты», «Контакты» и «Компания» раскрывают подменю — здесь это обычные пункты без подменю. Не воспроизведены выпадающие подменю и скрытие шапки при прокрутке вниз; телефон и слоган, которые были в прежней шапке прототипа, убраны — в шапке сайта их нет. В названии «Главный офис» на сайте опечатка («Гланый офис») — здесь она исправлена. Логотип — svg шапки сайта.
- Тема только **светлая**; токены повторяют `--theme-*` сайта. Серые плашки блоков деталей, рамка слайдера, превью под ним и блоки опций скруглены одинаково (5 px, от 900 px — 10 px, как плашки на сайте); блок цены повторяет собственные скругления сайта.

```
src/
  app/                  # точка входа, маршруты (routes.tsx), лейаут (шапка, содержимое, подвал), глобальные стили
  pages/
    catalog/            # / — каталог товаров
    product/            # /product/:slug — страница конфигуратора, loader маршрута
    not-found/          # 404
  widgets/
    site-header/        # шапка (заглушка по образцу сайта): логотип, меню, значки, счётчик корзины, меню на узких экранах
    site-footer/        # подвал (заглушка по образцу сайта): разделы-аккордеоны с пунктами-заглушками, копирайт; состав — config/footer-rows.ts
    product-gallery/    # галерея выбранного SKU: фото, чертёж, видео; предзагрузка фото остальных SKU
    product-configurator/ # название, шаги выбора, блок цены (цена, наличие, количество, «в корзину»)
    product-details/    # плашки описания, таблица характеристик, блок скачивания (паспорт)
  features/
    configure-product/  # хук useProductConfigurator (выбор в URL) и OptionPicker
    add-to-cart/        # количество (степпер) и кнопка корзины — правая часть блока цены
  entities/
    product/            # модель (SKU, выбор, наличие, галерея, валидация), данные, UI карточки/цены/остатка
    cart/               # хранилище корзины, значок со счётчиком для шапки
  shared/
    ui/                 # icon (в т.ч. значки шапки, блока скачивания и блока цены), choice-group, stub-link (ссылка-заглушка без адреса), media-slider (обёртка над Swiper: слайдер, полноэкранная галерея, плеер-постер EmbedPlayer)
    lib/                # format-price, format-years, use-document-title, prefers-reduced-motion, can-use-view-transition, preload-image
    config/             # маршруты
    styles/             # токены, reset, типографика, миксины, View Transitions
test/                   # настройка тестового окружения (вне FSD)
docs/                   # инструкции (добавление товара)
```

Правила слоёв, импортов, стилей и тестов — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Тесты и качество

- Vitest + Testing Library (jsdom): юнит-тесты логики (`model`), компонентов и страниц, интеграционные сценарии конфигуратора, тест целостности данных всех товаров.
- Браузерные API, которых нет в jsdom (`matchMedia`, `ResizeObserver`, размеры элементов для Swiper, `scrollTo`, воспроизведение видео, `showModal()` и `close()` у `<dialog>`), эмулируются в [`test/setup.ts`](test/setup.ts).
- `npm run check` — типы, ESLint, Steiger (правила FSD), тесты и сборка.
