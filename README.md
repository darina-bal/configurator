# Конфигуратор светильников (прототип)

Набросок конфигуратора товара для сайта centersvet.ru: оформление — в стилистике сайта (монохром, Montserrat, светлая тема; блоки под конфигуратором — серые скруглённые плашки, как на страницах товаров; шапка и подвал — заглушки по образцу сайта), логика и раскладка — как у конфигуратора Apple Watch (галерея слева, шаги выбора справа, цена, количество и кнопка «в корзину» внутри блока опций).

Конфигураторов будет много (почти на каждый товар), поэтому ядро универсально: товар описывается данными (опции + матрица SKU), а интерфейс и логика общие. Пока реализованы два товара: **LOOP.RT** (выбор цвета) и **LOCUS DUO** (выбор трека — встроенный или накладной — и цвета).

## Возможности

- **Универсальный конфигуратор.** Шаги выбора и позиции (SKU) описываются данными товара: новый товар — новый файл данных, код менять не нужно ([как добавить](docs/adding-a-product.md)).
- **Всё зависит от выбранного SKU:** цена, наличие, описание, характеристики и галерея (фото, чертёж, видео). Выбор хранится в адресе страницы (`?track=surface&finish=paint-white`) — ссылку на конкретную конфигурацию можно отправить.
- **Галерея на Swiper** по образцу centersvet.ru: прокрутка с зацикливанием, миниатюры, полноэкранный режим; смена цвета плавно перетекает в новый кадр.
- **Блок цены, описание, характеристики, шапка и подвал** повторяют вёрстку centersvet.ru. Ссылок на сайт нет — вместо них заглушки.
- **Корзина-заглушка** (счётчик в шапке, `localStorage`), адаптивная вёрстка от 390 px, доступность с клавиатуры, поддержка `prefers-reduced-motion`.

## Быстрый старт

Нужен Node.js ≥ 22.18 (проверено на 24).

```bash
npm install
npm run dev        # http://localhost:5173
```

Страницы: `/` — каталог, `/product/loop_rt_main` и `/product/locus_duo` — конфигураторы.

## Деплой на Vercel

Приложение — статический SPA: `npm run build` собирает его в `dist/`, переменных окружения нет. Vercel сам определяет Vite (команду сборки и папку `dist/`) и ставит dev-зависимости, нужные для сборки; версию Node берёт из `engines` в `package.json` (диапазон `>=22.18.0` подходит под 24.x, на которой проект и проверялся).

Единственный файл настроек — [`vercel.json`](vercel.json): правило `rewrites` отдаёт `index.html` на любой адрес, которого нет среди файлов сборки. Без него прямой заход на `/product/locus_duo?track=surface` (ссылка на конфигурацию, обновление страницы) закончился бы ответом 404: страницы существуют только в клиентском роутере. Побочный эффект: адрес, которого нет в приложении, тоже получает `index.html` с кодом 200, а страницу «не найдено» рисует само приложение.

Данные — статические модули в [`src/entities/product/api/data/`](src/entities/product/api/data), снимок с centersvet.ru на **12.10.2026**; при подключении бэкенда меняется только слой `api` ([catalog.ts](src/entities/product/api/catalog.ts)).

| Товар         | Страница-источник на centersvet.ru                        | SKU                   |
| ------------- | --------------------------------------------------------- | --------------------- |
| **LOOP.RT**   | `/product/loop_rt_main/`                                  | 4 (отделки)           |

## Структура проекта

```
src/
  app/                  # точка входа, маршруты (routes.tsx), лейаут (шапка, содержимое, подвал), глобальные стили
  pages/
    catalog/            # / — каталог товаров
    product/            # /product/:slug — страница конфигуратора, loader маршрута
    not-found/          # 404
  widgets/
    site-header/        # шапка (заглушка по образцу сайта): логотип, меню, значки, счётчик корзины, меню на узких экранах
    site-footer/        # подвал (заглушка по образцу сайта): разделы-аккордеоны с пунктами-заглушками, копирайт; состав — config/footer-rows.ts
    product-gallery/    # галерея выбранного SKU: фото, чертёж, видео; предзагрузка фото остальных SKU
    product-configurator/ # название, шаги выбора, блок цены (цена, наличие, количество, «в корзину»)
    product-details/    # плашки описания, таблица характеристик, блок скачивания (паспорт)
  features/
    configure-product/  # хук useProductConfigurator (выбор в URL) и OptionPicker
    add-to-cart/        # количество (степпер) и кнопка корзины — правая часть блока цены
  entities/
    product/            # модель (SKU, выбор, наличие, галерея, валидация), данные, UI карточки/цены/остатка
    cart/               # хранилище корзины, значок со счётчиком для шапки
  shared/
    ui/                 # icon (в т.ч. значки шапки, блока скачивания и блока цены), choice-group, stub-link (ссылка-заглушка без адреса), media-slider (обёртка над Swiper: слайдер, полноэкранная галерея, плеер-постер EmbedPlayer)
    lib/                # format-price, format-years, use-document-title, prefers-reduced-motion, can-use-view-transition, preload-image
    config/             # маршруты
    styles/             # токены, reset, типографика, миксины, View Transitions
test/                   # настройка тестового окружения (вне FSD)
docs/                   # инструкции (добавление товара)
```

Правила слоёв, импортов, стилей и тестов — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Тесты и качество

- Vitest + Testing Library (jsdom): юнит-тесты логики (`model`), компонентов и страниц, интеграционные сценарии конфигуратора, тест целостности данных всех товаров.
- Браузерные API, которых нет в jsdom (`matchMedia`, `ResizeObserver`, размеры элементов для Swiper, `scrollTo`, воспроизведение видео, `showModal()` и `close()` у `<dialog>`), эмулируются в [`test/setup.ts`](test/setup.ts).
- `npm run check` — типы, ESLint, Steiger (правила FSD), тесты и сборка.
