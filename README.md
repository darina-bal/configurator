# Конфигуратор светильников (прототип)

Набросок конфигуратора товара для сайта centersvet.ru: оформление — в стилистике сайта (монохром, Montserrat, светлая тема; блоки под конфигуратором — серые скруглённые плашки, как на страницах товаров; шапка и подвал — заглушки по образцу сайта), логика и раскладка — как у конфигуратора Apple Watch (галерея слева, шаги выбора справа, цена, количество и кнопка «в корзину» внутри блока опций).

Конфигураторов будет много (почти на каждый товар), поэтому ядро универсально: товар описывается данными (опции + матрица SKU), а интерфейс и логика общие. Пока реализованы два товара: **LOOP.RT** (выбор цвета) и **LOCUS DUO** (выбор трека — встроенный или накладной — и цвета).

## Возможности

- **Универсальный конфигуратор.** Набор шагов (опций) определяется данными товара: у LOOP.RT один шаг («Цвет»), у LOCUS DUO два («Трек», «Цвет»). Новый товар — новый файл данных, код менять не нужно ([как добавить](docs/adding-a-product.md)).
- **Раскладка как у Apple.** Слева липкая галерея, справа шаги выбора, под ними — блок цены с наличием, количеством и кнопкой корзины.
- **Блок цены — как на centersvet.ru**, но в правой колонке: серая плашка, слева «Цена с НДС 22%», цена и наличие с цветной точкой, справа (за вертикальным разделителем) количество со степпером «− 1 +» и серая кнопка с иконкой корзины. Артикул и гарантия под блоком не дублируются — они есть в таблице характеристик ниже. Размеры, шрифты и цвета сняты с живой страницы сайта, три ступени адаптива подстраиваются под ширину блока (крупная, компактная, в два ряд).
- **Шапка и подвал — заглушки по образцу centersvet.ru.** Шапка: логотип (ведёт на главную прототипа), меню «Продукты / Контакты / Компания / Поиск», значки международной версии, корзины со счётчиком и кабинета; на экранах уже 1024 px — кнопка меню и панель на весь экран, как на сайте. Подвал: чёрный, семь строк-аккордеонов («Наши консультанты», «Наши шоурумы», «Наши соцсети», «Кабинет дизайнера», «О компании», «Контакты», «Карьера») с «плюсом» справа и копирайтом. **Ссылок на сайт нет:** пункты меню, значки и пункты подвала — ссылки-заглушки (выглядят как на сайте, но без адреса: нажатие ничего не делает и вкладок не открывает), в соцсети и на страницы centersvet.ru из прототипа не попасть. На сайте у меню есть выпадающие подменю и шапка прячется при прокрутке вниз — здесь этого нет.
- **Блоки под конфигуратором — как на странице товара centersvet.ru:** плашки описания (заголовок и текст, у LOCUS DUO — три плашки серии), ниже слева серая плашка с таблицей характеристик, а справа от неё — плашка «блока скачивания» (3D Files, DIALux, Паспорт и инструкция). Фото и чертёж здесь не повторяются: они показаны только в галерее. На узких экранах плашки идут друг под другом: таблица, затем файлы.
- **Всё зависит от выбранного SKU:** цена, остаток («В наличии 162 шт» / «В наличии менее 50 шт» / «Нет в наличии» с зелёной, жёлтой и красной точкой), доступность кнопки, блоки описания, характеристики, галерея (фото, чертёж, видео).
- **Подсказки в самих опциях:** пометка «Нет в наличии» и перечёркнутый цвет-свотч. Цен и надбавок в опциях нет: цена считается и показывается только в блоке цены (и при добавлении в корзину).
- **Галерея выбранного светильника на Swiper:** слайды и превью под ними — только фото выбранного SKU, его чертёж размеров и видео (выбран белый цвет — фото белого светильника; выбран накладной трек — чертёж накладного). Вся галерея — это три слайда, и при смене опции они остаются на месте, меняется их содержимое: кадр, который смотрит пользователь, не сбрасывается. Смена опции плавно перетекает в новый кадр (перекрёстное затухание), листание галереи на выбор не влияет. **Слайдер ведёт себя как на centersvet.ru:** кадры прокручиваются по горизонтали (0,6 с), после последнего снова первый; листают кликом по краям кадра (зоны по 30 % ширины, при наведении проявляется стрелка; с 768 px) и свайпом, а также миниатюрами под кадром; рамка и превью под ней скруглены (5 px, от 900 px — 10 px). Нажатие на кадр картинки открывает **полноэкранную галерею**: чёрный экран, кадр по центру, крестик, счётчик «1 / 3», стрелки (у краёв экрана от 1280 px, ниже — по бокам счётчика), листание клавишами ←/→ и свайпом, закрытие крестиком или Esc. Галерея — нативный `<dialog>`: страница под ним не прокручивается и остаётся на прежнем месте, фокус возвращается на кадр, с которого открыли. Видео-слайды играют на месте, как раньше. Чёрточек-индикаторов, как у сайта, нет — их заменяют миниатюры.
- **Выбор хранится в адресе страницы** (`?track=surface&finish=paint-white`): ссылку на конкретную конфигурацию можно отправить, кнопки «назад/вперёд» работают.
- **Корзина-заглушка:** значок со счётчиком в шапке (рядом с остальными значками, как на сайте), сохранение в `localStorage`; количество выбирается в блоке цены и ограничено остатком с учётом уже лежащего в корзине.
- Адаптивная вёрстка (от 390 px), клавиатурная доступность (нативные radio, a11y-подписи слайдера по-русски), поддержка `prefers-reduced-motion` (кадры меняются без анимации). Хлебных крошек на странице нет.

## Стек

| Назначение    | Технология                                                               |
| ------------- | ------------------------------------------------------------------------ |
| UI            | React 19, TypeScript 6.0 (strict), React Router 7                        |
| Сборка        | Vite 8                                                                   |
| Стили         | SCSS (CSS Modules), шрифт Montserrat (`@fontsource-variable/montserrat`) |
| Слайдер       | Swiper 14 (готовая библиотека: прокрутка с зацикливанием, миниатюры)     |
| Архитектура   | Feature-Sliced Design, линтер Steiger                                    |
| Тесты         | Vitest 5, Testing Library, jsdom                                         |
| Качество кода | ESLint 10 (typescript-eslint, react-hooks), Prettier                     |

TypeScript закреплён на `~6.0`: `typescript-eslint` пока не поддерживает 7.x.

Известное замечание `npm audit`: транзитивная зависимость `braces` у dev-инструмента `steiger` (ReDoS на глубоко вложенных паттернах). В сборку и рантайм не попадает; исправление требует понижения `steiger`, поэтому оставлено как есть.

## Быстрый старт

Нужен Node.js ≥ 22.18 (проверено на 24).

```bash
npm install
npm run dev        # http://localhost:5173
```

Страницы: `/` — каталог, `/product/loop_rt_main` и `/product/locus_duo` — конфигураторы.

## Деплой на Vercel

Приложение — статический SPA: `npm run build` собирает его в `dist/`, переменных окружения нет. Vercel сам определяет Vite (команду сборки и папку `dist/`) и ставит dev-зависимости, нужные для сборки; версию Node берёт из `engines` в `package.json` (диапазон `>=22.18.0` подходит под 24.x, на которой проект и проверялся).

Единственный файл настроек — [`vercel.json`](vercel.json): правило `rewrites` отдаёт `index.html` на любой адрес, которого нет среди файлов сборки. Без него прямой заход на `/product/locus_duo?track=surface` (ссылка на конфигурацию, обновление страницы) закончился бы ответом 404: страницы существуют только в клиентском роутере. Побочный эффект: адрес, которого нет в приложении, тоже получает `index.html` с кодом 200, а страницу «не найдено» рисует само приложение.

## Структура проекта

```
src/
  app/                  # точка входа, маршруты (routes.tsx), лейаут (шапка, содержимое, подвал), глобальные стили
  pages/
    catalog/            # / — каталог товаров
    product/            # /product/:slug — страница конфигуратора, loader маршрута
    not-found/          # 404
  widgets/
    site-header/        # шапка (заглушка по образцу сайта): логотип, меню, значки, счётчик корзины, меню на узких экранах
    site-footer/        # подвал (заглушка по образцу сайта): разделы-аккордеоны с пунктами-заглушками, копирайт; состав — config/footer-rows.ts
    product-gallery/    # галерея выбранного SKU: фото, чертёж, видео; предзагрузка фото остальных SKU
    product-configurator/ # название, шаги выбора, блок цены (цена, наличие, количество, «в корзину»)
    product-details/    # плашки описания, таблица характеристик, блок скачивания (паспорт)
  features/
    configure-product/  # хук useProductConfigurator (выбор в URL) и OptionPicker
    add-to-cart/        # количество (степпер) и кнопка корзины — правая часть блока цены
  entities/
    product/            # модель (SKU, выбор, наличие, галерея, валидация), данные, UI карточки/цены/остатка
    cart/               # хранилище корзины, значок со счётчиком для шапки
  shared/
    ui/                 # icon (в т.ч. значки шапки, блока скачивания и блока цены), choice-group, stub-link (ссылка-заглушка без адреса), media-slider (обёртка над Swiper: слайдер, полноэкранная галерея, плеер-постер EmbedPlayer)
    lib/                # format-price, format-years, use-document-title, prefers-reduced-motion, can-use-view-transition, preload-image
    config/             # маршруты
    styles/             # токены, reset, типографика, миксины, View Transitions
test/                   # настройка тестового окружения (вне FSD)
docs/                   # инструкции (добавление товара)
```

Правила слоёв, импортов, стилей и тестов — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Тесты и качество

- Vitest + Testing Library (jsdom): юнит-тесты логики (`model`), компонентов и страниц, интеграционные сценарии конфигуратора, тест целостности данных всех товаров.
- Браузерные API, которых нет в jsdom (`matchMedia`, `ResizeObserver`, размеры элементов для Swiper, `scrollTo`, воспроизведение видео, `showModal()` и `close()` у `<dialog>`), эмулируются в [`test/setup.ts`](test/setup.ts).
- `npm run check` — типы, ESLint, Steiger (правила FSD), тесты и сборка.
